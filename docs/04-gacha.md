# 뽑기와 도감

**동물은 ‘알’로 뽑습니다. 출시 때 60종, 업데이트로 100종 이상을 목표로 하고, 6단계 등급으로 나눕니다.**

등급별 동물은 [05-animals.md](05-animals.md)에 있습니다.

## 등급과 확률

| 등급 | 확률 | 알 연출 |
|---|---|---|
| 흔함 | 50% | 하얀 알, 톡 깨짐 |
| 보통 | 28% | 무늬 알, 흔들한 뒤 깨짐 |
| 희귀 | 14% | 반짝이는 파란 알 |
| 영웅 | 6% | 보라 빛이 새어 나옴 |
| 전설 | 1.8% | 땅이 울리고 황금 금 |
| 신화 | 0.2% | 화면 전체가 무지개로 번짐 |

확률 합계는 100%입니다.

## 규칙

- **도감**: 못 뽑은 동물은 그림자만 보여서 "저거 뭐지?" 하고 궁금하게 만듭니다. 도감을 채울수록 보상을 줍니다.
- **색깔 변종**: 같은 동물도 낮은 확률로 다른 무늬(삼색 고양이, 하얀 호랑이)가 나와서 종 수를 크게 늘리지 않고도 모을 거리가 많아집니다.
- **중복 보상**: 이미 있는 동물이 나오면 그 동물의 친밀도가 오르고 코인을 돌려줍니다. 꽝 당첨 느낌을 없앱니다.
- **천장(보장)**: 알 50개를 깨는 동안 영웅 이상이 안 나오면 다음 알은 영웅 이상이 확정입니다.
- **서식지 테마**: 새 서식지가 열릴 때마다 새 동물이 뽑기에 추가됩니다. 서식지 목록은 [05-animals.md](05-animals.md#서식지)에 있습니다.

확률과 보장 횟수는 테스트하며 조정할 가정치입니다. 유료 뽑기를 넣게 되면 확률 공개가 법적 의무입니다.
