# MVP 범위와 AI 개발 단계

**첫 목표는 ‘동물 12종, 방 하나, 알 뽑기, 쓰다듬기’만 되는 웹 프로토타입으로, 뽑는 순간이 재밌는지 확인하는 것입니다.**

1. **프로토타입(핵심 재미 확인)**: 동물 12종(등급마다 2종), 탭으로 쓰다듬기와 밥 주기, 코인으로 알 뽑기와 부화 연출, 도감 화면, 휴대폰에 저장. 그림은 임시 이모지나 단순 일러스트로 시작.
2. **그림체 확정**: AI 이미지 도구로 강아지, 호랑이, 공룡 3종을 같은 스타일로 뽑아보고, 고른 스타일을 설명문(프롬프트)으로 고정해 나머지 동물에 재사용.
3. **보고 싶게 만드는 장치**: 부화 타이머, 동물 선물, 출석 보상, 친밀도와 성장 단계.
4. **동물 대량 추가**: 60종과 서식지 4개, 색깔 변종, 효과음.
5. **앱 출시 준비**: 앱으로 포장, 알림, 서버 저장, 수익 모델 결정.

AI로 만드는 방법은 단계마다 같습니다. 이 프로젝트에서 Claude가 코드를 짜고 미리보기 링크를 드리면, 현성님이 폰에서 해보고 느낌을 말해주시는 방식입니다. 코드는 이 저장소(cozy-pet)에 보관합니다.

## 진행 상황

- 1단계 프로토타입: 완료(웹, `web/` 폴더).
- 3단계 일부 구현: 부화 둥지(등급별 5분~8시간, 둥지 2칸), 하루 한 번 무료 알과 7일 연속 보너스(희귀 이상), 친밀도에 따른 성장 단계(아기, 어린이, 어른). 모든 값은 `web/config.js`에서 바꿉니다.
- 아직 안 한 것: 2단계 그림체 확정(AI 이미지 도구로 고른 스타일이 필요), 동물 선물 물어오기 연출 강화, 알림, 기간 한정 동물.
