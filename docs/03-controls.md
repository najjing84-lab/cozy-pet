# 매우 쉬운 조작

**규칙: 모든 행동은 탭 한 번 또는 드래그 한 번으로 끝난다. 글을 읽지 않아도 할 수 있어야 한다.**

| 하고 싶은 것 | 조작 | 동물 반응 |
|---|---|---|
| 쓰다듬기 | 동물을 손가락으로 문지르기 | 눈 감고 골골, 하트가 포로록 |
| 밥 주기 | 화면 아래 밥그릇 탭 | 냠냠 먹고 배가 통통 |
| 놀아주기 | 장난감을 동물 쪽으로 던지기(드래그) | 제자리에서 폴짝 뛰며 받기 |
| 여러 동물 보기 | 좌우로 밀기 | 방마다 다른 동물이 앉아 있음 |
| 알 깨기 | 알을 연타하기 | 금이 가다가 퐁! |
| 선물 받기 | 화면에 떨어진 코인, 별 탭 | 동물이 가져다 놓음 |

## 첫 화면

처음 3초 안에 "귀엽다, 해보고 싶다"가 들도록 만듭니다.

- 타이틀 화면에 통통 튀는 게임 이름, 12종 동물이 줄지어 지나가는 퍼레이드, 무지개빛으로 흔들리는 물음표 알을 보여줍니다.
- 처음 온 사람은 "톡! 눌러서 첫 알 깨기"를 누르면 바로 알을 두드려 깨고 첫 친구(강아지)를 만납니다. 설명을 읽기 전에 뽑는 재미부터 느끼게 합니다.
- 첫 친구를 만나면 손가락 그림이 동물을 문지르는 모습으로 쓰다듬기를 알려주고, 한 번 쓰다듬으면 사라집니다.
- 다시 온 사람은 "친구 N마리가 기다리고 있어요"를 보고 한 번 눌러 바로 방으로 들어갑니다.

## 방 안의 동물

- 동물은 방을 돌아다니지 않고, 바닥의 정해진 자리에 얌전히 앉아 있습니다. 그래서 언제든 바로 손가락으로 쓰다듬을 수 있습니다.
- 동물은 머리부터 발끝까지 전신으로 크게 보여줍니다. 마리 수가 적을수록 더 크게, 많아지면 줄을 맞춰 나란히 앉습니다.
- 가만히 있는 동안에도 숨 쉬듯 살짝 움직이고, 가끔 눈을 깜빡이거나 고개를 돌리거나 제자리에서 콩 뜁니다.

## 기본 규칙

- 배고픔, 슬픔 같은 스트레스 수치는 없습니다. 안 들어와도 동물이 죽거나 아프지 않고, "보고 싶었어"라며 반갑게 맞아줍니다.
- 한 손으로 들고 엄지로만 조작할 수 있도록 버튼은 화면 아래쪽 3분의 1에만 둡니다.
