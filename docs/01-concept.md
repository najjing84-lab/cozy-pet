# 컨셉과 기본 전제

**한 줄 컨셉: 손가락 하나로 키우고, 알을 깨서 강아지부터 공룡까지 100종이 넘는 동물을 모으는 힐링 수집 게임.**

정해지지 않은 부분은 아래 기본값으로 잡았어요. 바꾸고 싶으면 이 표를 바로 고치면 됩니다.

| 항목 | 기본값 | 이유 |
|---|---|---|
| 플랫폼 | 모바일 세로 화면 캐주얼 게임 | 짧게 자주 들어오는 게임에 가장 잘 맞음 |
| 프로토타입 | 웹(HTML5, 휴대폰 브라우저에서 실행) | 설치 없이 링크로 바로 테스트, AI로 만들기 가장 쉬움 |
| 정식 출시 | 웹을 앱으로 감싸 스토어 출시(나중에 결정) | 같은 코드를 재사용 |
| 타깃 | 10대~30대, 귀여운 것과 수집을 좋아하는 사람 | 조작이 쉬워 연령 폭이 넓음 |
| 그림체 | 2D, 둥글고 통통한 SD(2~3등신) 스타일 | 많은 종을 AI로 일관되게 그리기 쉬움 |
| 개발 방식 | 기획, 코드, 그림, 효과음 모두 AI로 제작 | 현성님 요청 |
| 수익 모델 | 우선 없음(프로토타입은 재미 검증만) | 재미가 확인된 뒤 광고 보상이나 유료 재화 검토 |
